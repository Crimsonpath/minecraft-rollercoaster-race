# 🎮 Super Easy Installation - .mcworld File

## The Easiest Way to Install!

Instead of manually copying folders, just use the **RollercoasterRace.mcworld** file!

## 📥 Installation (3 Steps!)

### Step 1: Download
Download the `RollercoasterRace.mcworld` file

### Step 2: Open
**Double-click** the `.mcworld` file

OR

**Right-click** → Open with → Minecraft

### Step 3: Play!
The world will automatically import into Minecraft with:
- ✅ Behavior pack already activated
- ✅ Resource pack already activated  
- ✅ All settings configured
- ✅ Ready to play!

## 🎯 That's It!

No manual folder copying needed! The .mcworld file contains everything:
- The world template
- Behavior pack (interactive dialogues)
- Resource pack (audio + textures)
- All settings pre-configured

## 🚀 After Import

1. Open Minecraft
2. You'll see "Rollercoaster Race World" in your worlds list
3. Click on it to edit settings
4. **Important:** Enable "GameTest Framework" in Experiments
5. Create the world
6. Use commands from `rollercoaster_commands.txt` to build the track
7. Type `/race` to start!

## 🔧 Troubleshooting

**Issue: File won't open**
- Make sure you have Minecraft Bedrock Edition installed
- Try right-click → Open with → Minecraft

**Issue: Import fails**
- Check you have enough storage space
- Make sure Minecraft is updated to 1.20.0+

**Issue: Packs not active**
- After importing, edit the world
- Check that both packs are in the "Active" section
- Enable "GameTest Framework" under Experiments
