# 🎢 Minecraft Rollercoaster Race

A stunning 5-player competitive rollercoaster race level for Minecraft with automation scripts for the Minecraft Editor.

## 📋 Project Overview

This repository contains everything you need to build and play an exciting rollercoaster race level in Minecraft. The project includes:

- **Level Files:** Pre-built rollercoaster structure with 5 parallel tracks
- **Installation Scripts:** Multiple methods to import the level into your world
- **Minecraft Editor Scripts:** JavaScript automation for building in the Minecraft Editor
- **Documentation:** Complete setup and gameplay instructions

## 🎯 Features

- **5 Parallel Tracks:** Perfect for competitive 4-5 player races
- **Vibrant Theme:** Fantasy Carnival aesthetic with colorful blocks
- **Exciting Ride:** Includes loops, drops, and twists

## 🚀 Quick Start

### Option 1: Using Minecraft Commands (Easiest)

1. Open your Minecraft world with cheats enabled
2. Copy commands from `rollercoaster_commands.txt`
3. Paste into a command block or chat
4. The level builds automatically!

### Option 2: Using Minecraft Editor Script

1. Open the Minecraft Editor
2. Load the project world
3. Open the Script Editor
4. Paste the contents of `scripts/build_rollercoaster.js`
5. Run the script
6. Watch the level build automatically!

### Option 3: Using a Schematic Tool

1. Use WorldEdit, Amulet, or similar tools
2. Import `rollercoaster_schematic.json`
3. Place in your world
4. Save changes

## 🎮 How to Play

1. Gather 4-5 players
2. Each player chooses a colored track
3. Start at the same time
4. Race to the finish line!
5. First one through wins!

## 🛠️ Customization

You can easily customize the level by editing the scripts:

- **Track Length:** Modify the `trackLength` variable
- **Number of Tracks:** Change `numTracks` value
- **Block Types:** Edit the block materials
- **Decorations:** Add more themed elements
- **Difficulty:** Adjust loop sizes and drop heights

## 💡 Tips for Best Experience

- Use powered rails for the tracks (they auto-accelerate minecarts)
- Add redstone torches under rails for power
- Use different colored wool for each track
- Add spectator areas for players to watch
- Consider adding a leaderboard system

## 🔧 Technical Details

- **Minecraft Version:** Java & Bedrock compatible
- **Player Count:** 4-5 recommended (can scale up to 10+)
- **Build Time:** ~5 minutes with scripts, ~30 minutes manual
- **World Size:** ~300x300 blocks
- **Difficulty:** Medium (suitable for all ages)
