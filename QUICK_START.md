# 🚀 Quick Start Guide - Minecraft Rollercoaster Race

## Get Racing in 5 Minutes!

### Step 1: Download (30 seconds)

Clone or download from GitHub:
```bash
git clone https://github.com/Crimsonpath/minecraft-rollercoaster-race.git
```

Or download the ZIP file: `minecraft-rollercoaster-ai-enhanced.zip`

### Step 2: Install Packs (2 minutes)

**Behavior Pack:**
1. Copy `behavior_pack` folder
2. Paste into: `com.mojang/behavior_packs/`
3. Rename to: `RollercoasterRace_BP`

**Resource Pack:**
1. Copy `resource_pack` folder
2. Paste into: `com.mojang/resource_packs/`
3. Rename to: `RollercoasterRace_RP`

**Where to find these folders:**
- **Windows:** `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\`
- **Android:** `Internal Storage/games/com.mojang/`
- **iOS:** `Minecraft/games/com.mojang/`

### Step 3: Create World (1 minute)

1. Open Minecraft Bedrock Edition
2. Create a new world
3. Go to **Behavior Packs** → Add "Rollercoaster Race"
4. Go to **Resource Packs** → Add "Rollercoaster Race Resources"
5. Enable **GameTest Framework** in settings
6. Create the world

### Step 4: Build Track (1 minute)

**Option A - Commands (Fastest):**
1. Enable cheats
2. Open `rollercoaster_commands.txt`
3. Copy and paste commands into chat
4. Track builds instantly!

**Option B - Script:**
1. Open Minecraft Editor
2. Load `scripts/build_rollercoaster.js`
3. Run the script

### Step 5: Start Racing! (30 seconds)

1. Type `/race` in chat
2. Choose your track
3. Get in a minecart
4. Click "I'm Ready!"
5. Listen for countdown
6. **GO!** 🏁

## 🎮 Essential Commands

- **`/race`** - Open main menu
- **`/help`** - Show instructions
- **`/tracks`** - Choose track

## 🏁 Racing Tips

1. **Choose Your Track** - Each track is numbered 1-5
2. **Wait for Countdown** - Don't jump the start!
3. **Stay Seated** - Don't exit your minecart
4. **Race Friends** - Up to 5 players can race at once
5. **Have Fun!** - It's all about the experience!

## 📱 Multiplayer Setup

**Host:**
1. Install both packs
2. Build the track
3. Invite friends to world

**Players:**
1. Join the world
2. Type `/race` to start
3. Choose an available track

## 🆘 Quick Troubleshooting

**Dialogs not showing?**
→ Enable "GameTest Framework" in world settings

**No sound?**
→ Check that resource pack is activated

**Track not building?**
→ Make sure cheats are enabled

**Script errors?**
→ Check behavior pack is in correct folder
