🚀 QUICK INSTALL
----------------

1. Copy behavior_pack to: com.mojang/behavior_packs/
2. Copy resource_pack to: com.mojang/resource_packs/
3. Create new world with both packs enabled
4. Enable "GameTest Framework"
5. Run commands from rollercoaster_commands.txt
6. Type /race to start!
