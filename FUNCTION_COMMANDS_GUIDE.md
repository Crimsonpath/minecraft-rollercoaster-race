# 🎮 Easy Build with Function Commands

## No More Copy-Pasting!

Instead of copying thousands of lines of commands, just use these simple function commands!

## 🚀 Super Simple - One Command!

After installing the behavior pack, just type this **ONE** command in chat:

```
/function build_all
```

That's it! The entire rollercoaster will build automatically! 🎉

## 📋 What Happens

When you run `/function build_all`, it will:

1. ✅ Clear the build area
2. ✅ Build Track 1 (Red Lightning)
3. ✅ Build Track 2 (Blue Thunder)
4. ✅ Build Track 3 (Yellow Comet)
5. ✅ Build Track 4 (Green Flash)
6. ✅ Build Track 5 (Purple Storm)
7. ✅ Show completion message

**Total time:** About 5-10 seconds!

## 🎯 Individual Track Commands

You can also build tracks one at a time:

```
/function setup              # Clear area and prepare
/function build_track1       # Build Red track only
/function build_track2       # Build Blue track only
/function build_track3       # Build Yellow track only
/function build_track4       # Build Green track only
/function build_track5       # Build Purple track only
```

## 📖 Step-by-Step Instructions

### Step 1: Install the Pack
1. Double-click `RollercoasterRace.mcaddon`
2. Minecraft will import the packs

### Step 2: Create World
1. Create new world
2. Activate "Rollercoaster Race" behavior pack
3. Activate "Rollercoaster Race Resources" resource pack
4. Enable "GameTest Framework" in Experiments
5. Enable cheats
6. Create the world

### Step 3: Build the Track
1. Type in chat: `/function build_all`
2. Wait 5-10 seconds
3. Done! ✓

### Step 4: Start Racing
1. Type: `/race`
2. Choose your track
3. Get in a minecart
4. Race! 🏁

## 🔧 Troubleshooting

### "Unknown command: function"
**Solution:** Make sure the behavior pack is activated in your world

### "Unknown function"
**Solution:** 
1. Check that behavior pack is in the Active section
2. Make sure you typed the command correctly
3. Try `/reload` then try again

### Nothing happens
**Solution:**
1. Make sure cheats are enabled
2. Check you're in creative or have operator permissions
3. Verify behavior pack is properly installed

### Track builds but looks wrong
**Solution:** Run `/function setup` first to clear the area, then `/function build_all`

## 💡 Pro Tips

1. **Fly up** after running the command to watch the tracks build!
2. **Use `/tp 40 80 0`** to teleport to a good viewing position
3. **Run `/function setup`** if you want to rebuild from scratch
4. The tracks are built at **Y=64** (sea level)
