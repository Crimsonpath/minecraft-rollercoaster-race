# 🎮 EASIEST Installation Method - .mcaddon File

## What is .mcaddon?

An **.mcaddon** file is Minecraft's official format for installing add-ons (behavior packs + resource packs) with **one click**!

## ✨ Super Simple Installation

### Step 1: Download
Download **RollercoasterRace.mcaddon**

### Step 2: Double-Click
**Double-click** the `.mcaddon` file

OR

**Right-click** → Open with → Minecraft

### Step 3: Automatic Import!
Minecraft will automatically:
- ✅ Import the behavior pack
- ✅ Import the resource pack
- ✅ Install them in the correct folders
- ✅ Make them available for use

### Step 4: Create World
1. Open Minecraft
2. Click "Create New World"
3. Go to **Behavior Packs** → You'll see "Rollercoaster Race" in Available
4. Click **Activate** to move it to Active
5. Go to **Resource Packs** → You'll see "Rollercoaster Race Resources"
6. Click **Activate** to move it to Active
7. Go to **Experiments** → Enable "GameTest Framework"
8. Click **Create**

### Step 5: Build the Track
Once in the world:
1. Enable cheats: `/gamemode creative`
2. Copy commands from `rollercoaster_commands.txt`
3. Paste into chat to build the track

### Step 6: Race!
Type `/race` to start racing!

## 🔧 Troubleshooting

### "Import failed" error
**Solution:** Make sure you're using Minecraft Bedrock Edition (not Java Edition)

### File won't open
**Solution:** 
1. Right-click the file
2. Choose "Open with"
3. Select "Minecraft"

### Packs don't appear
**Solution:**
1. Close Minecraft completely
2. Reopen it
3. The packs should now appear in "Create New World"

### Can't activate packs
**Solution:** Make sure your Minecraft is version 1.20.0 or higher
